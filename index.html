    Vendor compatibility optional

    Load one whole-body DICOM from your camera. The export copies its header layout and vendor tags so the vendor's software reads it like its own. Patient details from that file are never copied.

    The DICOM is an NM Whole Body object with one frame per view (normally ANT + POST) that keeps the original patient and study, ready to import into your workstation or PACS.
